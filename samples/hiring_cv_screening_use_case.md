# Hiring CV Screening Assistant

The purpose of the AI system is to screen job applications, rank candidates for employment, and summarize CVs for recruiters.

Recruiters use the tool during an EU hiring workflow. The affected persons are job candidates applying for open roles.

Input data includes CVs, application answers, work history, education history, skill descriptions, and recruiter notes. The system processes this information to produce scores, rankings, shortlists, recommendations, and generated summaries.

The tool uses an LLM language model to summarize candidate profiles and an automated scoring model to rank candidates. It is intended as decision support: recruiters review recommendations before making interview or hiring decisions.

Human oversight exists because recruiters can approve, reject, or override recommendations. Current uncertainty remains around bias testing, logging, monitoring, provider documentation, and the exact provider/deployer responsibility split.
